# Synthetisches Papywizard-Beispiel

[example.xml](example.xml) zeigt zwei vollständig abgeschlossene Papywizard-Bildeinträge mit nullbasierten IDs. Die Positionen und Zeitpunkte sind frei gewählte Beispieldaten, keine reale Messreihe und kein Bildqualitätsnachweis.

`yaw` und `pitch` stehen in Grad. Die Android-Konvention verwendet `roll=0`. Windows' bisheriger Writer verwendet `roll=90`; diesen Unterschied bei einem konkreten Stitcher-/Kameraorientierungsworkflow prüfen. Weitere Details: [Datenmodell](../../docs/06-protokoll-und-datenmodell.md).
